What the predictions are made of

Geometry is still the first witness. The learned model is the second.

This pipeline's movement labels start from geometric rules compared against constants fixed before any clip was seen. A learned second opinion and detector fusion now run in auto mode: strong geometry is not silently overridden, and a weak call can be corrected only when the learned detector has enough confidence and margin. This page reads the modules at request time — including the constants, model path, fusion thresholds, provenance, and source comments explaining each value. A value here is the value your next run will use.
